ATLAS FLOW 사용법

행 하나가 산업 밸류체인 하나입니다. 왼쪽에서 오른쪽으로 상류 → 중류 → 하류 → 최종 수요가 흐르고, 같은 단계는 셀 안에 나란히 놓입니다. 위의 다이아몬드는 수요를 내리는 테마입니다.
마우스 올림그 노드의 관계선만 밝아집니다 (나머지는 그대로)
클릭관계 고정 조명 + 오른쪽 카드. 한 홉 실선, 두 홉 흐림, 나머지 물러남
체인 이름 클릭그 행만 펼치고 나머지 행은 접힙니다. 다시 누르면 복귀
+N 배지기업 펼침 (딥다이브 완료 종목은 진하게)
휠 / Shift+휠확대·축소 / 좌우 이동. 드래그 = 이동. 트랙패드 두 손가락 가능
0 · 1 · + · −전체 보기 · 실제 크기 · 확대 · 축소
/ · Esc검색 · 선택 해제/닫기
교차 연결체인을 가로지르는 관계선을 항상 표시 (기본은 선택할 때만)
전파 재생이번 갱신의 전파 체인을 한 단계씩 (재생·이전·다음)
노드 왼쪽 위 금색 점 = 이번 갱신에서 티어가 바뀐 산업(채움) 또는 판정 근거가 갱신된 산업(테두리). 표시는 딥다이브 산출의 인용이며 매매 의견이 아닙니다.
